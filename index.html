AirNotte는 여행 성향을 15가지 기준으로 분석하고, 동선 최적화와 실시간 검증이 끝난 '믿을 수 있는' 일정을 제안합니다.

기능 · FEATURES
01 / PROFILE

대화형 성향분석

설문이 아닌 대화를 통해 취향을 15가지 데이터 프로필로 변환합니다.

02 / ITINERARY

맞춤일정 자동생성

분석된 성향을 바탕으로 일정 전체를 자동으로 설계합니다.

03 / DAILY

일자별 상세

하루 단위로 시간·장소·이동을 정밀하게 구성해 보여줍니다.

04 / PLACES

장소추천

취향 데이터로 명소와 맛집을 큐레이션합니다.

05 / ROUTE

동선지도

OSRM 기반 경로 연산으로 이동 거리와 시간을 최소화합니다.

06 / VERIFY

실시간 검증

영업시간·휴무일·날씨를 교차 검증해 실행 가능한 일정만 제공합니다.
